# Chat Incognito  

Chat Incognito is a **real-time chat application** built with **React (Vite)** and **Socket.IO**.  
It allows users to communicate instantly without any database, ensuring privacy and no data storage.
Simply enter your name, join the chat, and start talking securely. 

---

## ❓ Why Chat Incognito ??
- 🔒 **Privacy First**: No database, no chat history — messages exist only during the session.  
- ⚡ **Instant Sharing**: Just enter your name and start chatting — no signup, no login.  
- 💻 **Cross-Device Convenience**: Need to share code or text between your PC and laptop? Forget logging into WhatsApp — Chat Incognito lets you send it instantly.
- 🕵️ **Incognito Mode**: Once you close the tab, your session and messages disappear, keeping talks private.  

---

## 🚀 Features
- Real-time messaging powered by **Socket.IO**.  
- No database — messages are stored temporarily in session storage.  
- Online user count with live updates.  
- Typing indicator (see who’s typing).  
- Dark/Light mode toggle.
- Notification Sound - Get a sound alert whenever you receive a new message.
- System messages when users join/leave.  
- Instant join — just enter your name, no signup/login needed.  

---

## 🛠️ Tech Stack
- **Frontend**: React (Vite), TailwindCSS  
- **Backend**: Node.js, Express, Socket.IO
